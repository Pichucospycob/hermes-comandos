📌 Referencia CLI

Flags Globales

hermes [flags] [command]

Todos los comandos aceptan estos flags:

--version, -V Mostrar versión   --resume, -r SESSION Reanudar sesión por ID o título   --continue, -c [NAME] Reanudar por nombre o la más reciente   --worktree, -w Modo worktree git aislado (agentes paralelo)   --skills, -s SKILL Precargar skills (separar con coma)   --profile, -p NAME Usar perfil con nombre   --yolo Saltar aprobación de comandos peligrosos   --pass-session-id Incluir ID de sesión en el system prompt

Chat

hermes chat [flags]

Modo interactivo de chat. Sin subcomando usa chat por defecto.

-q, --query TEXT Consulta única, no interactiva   -m, --model MODEL Modelo (ej: anthropic/claude-sonnet-4)   -t, --toolsets LIST Lista de toolsets separada por comas   --provider PROVIDER Forzar provider (openrouter, anthropic, etc.)   -v, --verbose Salida verbosa   -Q, --quiet Suprimir banner y spinner   --checkpoints Habilitar checkpoints de sistema de archivos (/rollback)   --source TAG Tag de origen de sesión (default: cli)
